# 课程字幕准确解读

`interpret-course-subtitles` 是面向通用课程的 Codex skill。它帮助 agent 在答疑、总结、教学和笔记任务中，辨认语音识别字幕里的专业术语、缩写与符号，并区分可靠解读和仍需核验的内容。

## 使用方式

将本仓库放入 Codex 的 skills 目录，文件夹命名为 `interpret-course-subtitles`，确保文件夹下直接包含 `SKILL.md`。若当前聊天尚未发现新技能，可在新聊天中调用。

示例请求：

```text
请使用 $interpret-course-subtitles 解读本项目的课程字幕，并总结这一节。
```

也支持课程答疑、笔记整理和教学场景中的自动技能选择。默认在阅读时核验术语，直接完成用户要求的任务；只有用户明确要求时，才输出完整校订副本。

## 工作方式

1. 识别课程，查找项目已有教材、讲义、课件和术语表。
2. 每门新课程询问是否在项目目录建立独立术语表；已有选择沿用，不重复询问。未同意时不创建。
3. 已有可用参考资料时先使用；没有时才询问是否添加。
4. 从前后完整论证段提出术语候选，结合课程定义、其他出现位置及必要的公开检索交叉核验。
5. 单独检查否定词、数值、单位、公式和条件，保留候选冲突与原文定位。

公开资料可以验证术语含义，但不能证明老师在某一时刻的确切原话。技能区分“原话/课程用词已核对”“高把握解读”“待核验”和“无法辨认”，不承诺固定识别准确率。

## 范围和资料处理

- 适用于 TXT、SRT、VTT 和逐字稿，课程学科不限。
- 不负责录播网站提取或音视频批量转写。
- 不覆盖原始字幕，不进行无条件近音词全局替换。
- 公开检索只使用必要概念，不默认上传整份非公开字幕或课程文件。
- 课程术语表保存在各自项目，不写入 skill 本体或全局词典。
- 本仓库只包含通用指令、合成示例和使用说明，不包含真实课程字幕、账号信息、个人资料或本机路径。
